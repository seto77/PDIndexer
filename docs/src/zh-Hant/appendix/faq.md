# Q&A

本頁收集了使用者實際提出過的問題，著重於常見問題與容易誤解之處。關於錯誤與啟動問題，另請參閱 [疑難排解](troubleshooting.md)。

## 首先嘗試的做法 {#first-steps}

### 發生異常（不顯示繞射線、無法讀取檔案、啟動時出錯）。首先該嘗試什麼？

請先在本頁中尋找與症狀相符的項目。不顯示繞射線時，原因幾乎都是輻射種類或波長的設定（[繞射線與晶體清單](#peaks-and-crystals)）。若仍未解決，請依下列順序嘗試。

1. 更新到最新版本（`說明` ▸ `程式更新`，或從 [發行頁面](https://github.com/seto77/PDIndexer/releases/latest) 下載）。
2. 勾選 `選項` ▸ `清除登錄檔 (勾選後重新啟動)`，然後結束並重新啟動 PDIndexer。PDIndexer 會將視窗位置、入射光設定等儲存在登錄檔中，從舊版本沿用的設定可能會造成問題。
3. 若晶體清單看起來不正常，請執行 `檔案` ▸ `將晶體還原為初始狀態`。

!!! warning "會遺失的內容"
    - **清除登錄檔** 會刪除已儲存的設定以及 **在巨集視窗中登錄的巨集**。請事先將需要的巨集匯出為 `.mcr` 檔案。晶體清單並不儲存在登錄檔中，而是儲存在另一個檔案（`%APPDATA%\PDIndexer\PDIndexer\default.xml`）中，因此清除登錄檔不會刪除它。
    - **還原晶體清單** 會捨棄您新增或編輯過的晶體。請事先以 `檔案` ▸ `儲存晶體` 儲存需要的晶體。

### 將 PDIndexer 與 IPAnalyzer 搭配使用時，出現錯誤或數值不正確。

[IPAnalyzer](https://github.com/seto77/IPAnalyzer) 與 PDIndexer 共用一個通用程式庫，並透過剪貼簿交換資料。若只更新其中一個，交換格式可能不一致，進而造成錯誤或數值不正確。**請同時將兩者都更新到最新版本。**

## 安裝與啟動 {#install}

### 無法在沒有系統管理員權限的 PC 上安裝 PDIndexer，或原則封鎖了 MSI。

請使用 **免安裝 ZIP 版本**（x64 為 `PDIndexer-v.<ver>.zip`，Arm64 為 `PDIndexer-v.<ver>_arm64.zip`）。其中已內含執行階段，因此既不需要 MSI，也不需要另外安裝 .NET Desktop Runtime。將整個資料夾解壓縮到可寫入的位置，然後執行解壓縮後資料夾中的 `PDIndexer.exe`。PDIndexer 本身以一般使用者權限執行。

MSI 版本與 ZIP 版本的差異請參閱 [執行環境與安裝](runtime-and-installation.md)。

!!! note
    PDIndexer 是未簽署的研究用軟體，因此在下載或第一次執行時，Windows（SmartScreen）或瀏覽器可能會發出警告。請在瀏覽器的下載清單中選擇 **更多資訊** ▸ **保留**；在執行時的警告中選擇 **其他資訊** ▸ **仍要執行**。

### 明明已安裝 .NET，卻出現「You must install .NET Desktop Runtime」。

原因通常是下列其中之一。

- **主要版本不對。** PDIndexer 所需的 .NET 版本會隨 PDIndexer 的版本而改變。請安裝所使用版本所註明之版本的 **Desktop Runtime**。只安裝單純的「.NET Runtime」是不夠的。
- **架構不對。** x64 版的 PDIndexer 需要 x64 執行階段；Arm64 版則需要 Arm64 執行階段。在 Arm 架構的 Windows（Snapdragon PC 等）上，請使用 Arm64 安裝程式 `PDIndexer-setup_arm64.msi`。
- 若仍無法執行，已內含執行階段的 **免安裝 ZIP 版本** 是最可靠的選擇。

## 繞射線與晶體清單 {#peaks-and-crystals}

### 勾選了晶體，卻不顯示繞射線，或繞射線位置偏差很大。

請先確認下列事項。

- [`在輪廓上方顯示峰`](../3-crystal-parameter.md) 已開啟，且該晶體在晶體清單中已勾選。
- **測量時的輻射種類與波長（或能量）設定正確。** CSV 等文字資料常不含波長資訊；此時請在讀取檔案時顯示的對話方塊中，指定測量所用的輻射種類與波長。用於顯示的輻射種類與波長可在主視窗的 [`水平軸` 頁籤](../1-main-window.md#horizontal-axis-tab) 中確認。
- 繞射線不在繪製範圍之外。請嘗試擴大水平軸的範圍（尤其是中子 TOF）。
- 若只有某一種晶體不顯示，請確認其晶格常數與原子位置是否偏差很大，並與內建資料庫中的同一物質比較。

### 拖曳繞射線後晶格常數改變了，重新啟動也無法復原。

由於 `選項` ▸ `關閉時儲存晶體清單` 預設為開啟，拖曳繞射線所改變的晶格常數會在 PDIndexer 關閉時儲存。因此重新啟動並無法還原變更。

- 若要回到本次工作階段中載入該晶體時的晶格常數，請在晶體資訊上按右鍵並選擇 `還原晶胞常數`。
- 若要將整個晶體清單回到剛安裝後的狀態，請選擇 `檔案` ▸ `將晶體還原為初始狀態`。

### 晶體清單中出現奇怪的數值或重複項目，或缺少壓力標準物質（Au、Pt 等）。

`檔案` ▸ `將晶體還原為初始狀態` 會還原包含壓力標準物質在內的初始晶體清單。您自行新增的晶體會遺失，如有需要請事先儲存。

### 強度比未被計算，所有繞射線的高度都相同。

要計算強度比，晶體必須含有原子位置，且必須開啟 [`計算強度比`](../3-crystal-parameter.md)。輻射設定錯誤也會使強度不正確。詳情請參閱 [疑難排解](troubleshooting.md)。

### 如何從 CSManager 或 CIF 檔案匯入晶體？

- **從 CSManager 匯入**：先開啟 PDIndexer 的 `繞射線/結晶資訊` 視窗並開啟 `選項` ▸ `監視剪貼簿`，然後在 CSManager 中選取該晶體。不需要先匯出 CIF。
- **CIF / AMC 檔案** 可以拖放到 `繞射線/結晶資訊` 視窗的晶體資訊區域。
- 也可以搜尋 **內建晶體資料庫**（AMCSD）。請參閱 [晶體參數](../3-crystal-parameter.md)。

無論哪種方式，晶體都會顯示在晶體資訊區域中。按下 `新增` 即可將其保留在晶體清單中。

### 能否將 X 光資料與電子（或其他波長）資料疊加在同一水平軸上？

可以。PDIndexer 只有一個水平軸，所有已載入的圖譜都會換算為在 `水平軸` 頁籤中選擇的輻射種類與波長。例如，電子繞射圖譜可以用 Cu Kα 的 2θ 刻度顯示。

若 `水平軸` 頁籤中的 `讀取圖譜後，變更水平軸` 為開啟狀態，軸設定會切換為每次新載入檔案的設定。若要固定水平軸以便比較，請取消此選項。

## 讀取圖譜與水平軸 {#profiles-and-axis}

### 主視窗的 `水平軸` 頁籤與圖譜參數視窗中的 `座標軸設定` 有什麼不同？

- `水平軸` 頁籤（主視窗）只決定 **資料的顯示方式**；圖譜資料本身不會改變。
- [`座標軸設定`](../4-profile-parameter.md#axis-setting)（圖譜參數視窗）會改寫 **圖譜的測量條件**（輻射種類、波長、取出角等）。若讀取檔案時選錯了輻射種類或波長，請在此更正。若以錯誤的 **單位** 輸入了數值，請重新讀取原始檔案。

### 能量色散（白色 X 光）資料（`.npd` / `.nxs`）的水平軸不正確，或不顯示繞射線。

請在讀取檔案時顯示的對話方塊中，確認 **能量單位（eV / keV）**、**2θ**，以及（對於 `.nxs`）**通道—能量校正係數** 與測量條件一致。`.npd` 檔案使用檔案中的能量欄，因此也請確認原始檔案中的數值與單位。單位錯誤會使峰位置大幅偏移。

### PDIndexer 能否讀取 GSAS `.gsa` 檔案（2θ 以釐度為單位）或 q（波數）軸的資料？

可以。

- 對於 `.gsa` 檔案（以空格分隔的三欄，2θ 以釐度為單位），請在資料轉換對話方塊中選擇 2θ 作為水平軸，並選擇釐度（centi-degree）作為單位。
- 對於 q（波數）軸的資料，請選擇 q 作為水平軸。也可以在 q 軸上精修晶格常數。

## 峰擬合與晶格常數 {#fitting}

### `搜尋範圍` 應設為多少？改變它時體積也會跟著變。

`搜尋範圍` 是峰中心兩側各自的搜尋寬度。請從峰的 **半高寬（FWHM）的 2～3 倍** 開始，若與相鄰的峰重疊則縮小。範圍過寬會納入其他峰或背景，過窄則會截掉峰的尾部；兩者都會使擬合位置偏移。使用較多的 **高角度峰** 可提高晶格常數的精度。

### `最佳化的晶胞參數` 中顯示的數值是否已套用至晶體？

沒有。`最佳化的晶胞參數` 只是 **顯示** 由所選反射與擬合條件得到的數值。若要覆寫晶體的晶格常數，請按 `套用至晶體`。若要在不改變晶體的情況下使用這些數值，請使用 `複製到剪貼簿`。多按幾次 `套用至晶體` 可能有助於收斂，因為每次都會更新計算出的繞射線位置。

### 選取了相同的反射，體積的誤差卻突然變大。

峰擬合（對各峰擬合函數）與晶格常數精修是彼此獨立的計算。PDIndexer 只在各反射的搜尋範圍內尋找峰，因此若其他相的峰或雜訊落入該範圍，就會有錯誤的 d 值進入晶格常數的計算。

- 在反射清單中確認各反射的擬合情形，排除可疑的峰或弱峰。
- 訊噪比不佳時，先只用強峰精修，之後再加入較弱的峰。所需獨立反射的數目至少要等於該晶系獨立晶格常數的個數（立方晶系為 1，三斜晶系為 6），若要估計誤差則需要更多。
- 對於弱峰或重疊嚴重的圖譜，Rietveld 分析等全圖譜擬合可能較為合適。

晶格常數及其誤差的計算方式請參閱 [演算法解說](algorithms.md#lattice-refinement)。

## 連續分析與巨集 {#sequential-and-macro}

### 我想自動擬合大量圖譜（時間解析、壓力步進等），並求得晶格常數或壓力。

請使用 [連續分析](../7-sequential-analysis.md)（從主視窗的工具列或以 `Ctrl+Shift+S` 開啟）。執行前請 **開啟峰擬合視窗** 並選擇晶體與反射。至少需要四個圖譜。結果可以自動儲存。

- 一次讀取數千個圖譜會占用大量記憶體。請先以約 100 個圖譜確定條件，再對全部資料執行。
- 直接從網路資料夾讀取會很慢。請在分析前將檔案複製到本機磁碟。
- 若晶格常數在序列中變化很大，峰可能會離開其搜尋範圍，而抓到其他的峰。開啟 `容許係數` 後，體積與 **執行開始時的體積** 相差超過設定值（%）的點會以 NaN 輸出。

### 連續分析能否同時擬合多個相（例如樣品與壓力標記物）？

所有已勾選晶體的峰都會被擬合（將峰分離設為 `對所有晶體` 時，不同相之間重疊的峰會一併分離）。不過，每次連續分析只會記錄峰擬合視窗中所選的一種晶體的晶格常數與壓力。若要取得其他相的結果，請選擇該晶體後再次執行，或使用在晶體之間切換的 [巨集](../8-macro.md)。

### 我對依方位角分割的圖譜進行了應力解析，但 `Singh 方程式` 分頁是空的。

只有當 **圖譜清單中第一個圖譜的名稱以 `whole` 結尾** 時，才會進入應力解析模式。對於第二個以後的圖譜，名稱中 **最後一個連字號之後** 的文字會被讀取為方位角（度）（例如 `sample-30`）。另請確認至少已載入四個圖譜，且峰擬合視窗為開啟狀態。在一般執行（非應力模式）中，`Singh 方程式` 分頁會保持空白。詳情請參閱 [連續分析](../7-sequential-analysis.md)。

### 以逗號作為小數分隔符號時，連續分析 CSV 的欄位會錯位。

連續分析的 CSV 直接沿用畫面上顯示的數字，因此若小數分隔符號為逗號（`1,5`），小數部分就無法與欄位分隔符號區分。目前請使用結果分頁上的 `複製` 將表格以定位字元分隔的文字複製，再以定位字元分隔資料的形式貼到試算表中。圖譜本身的 CSV 匯出（`檔案` ▸ `匯出選取的輪廓`）無論地區設定為何，一律以 `.` 作為小數分隔符號。

### 巨集以什麼語言撰寫？檔案路徑該如何書寫？

巨集以 **Python（IronPython）** 撰寫。Windows 路徑請以正斜線書寫（`'C:/data/sample.pdi2'`），或寫成原始字串（`r'C:\data\sample.pdi2'`）。可用的函式列於 [巨集](../8-macro.md) 的函式參考中。

## 狀態方程 {#eos}

### 我輸入了溫度。結果作為高溫下的壓力是否有效？

有些狀態方程（EOS）在原始論文中沒有溫度項（等溫方程），此時輸入的溫度不會被使用。對文獻中的數值表進行內插的 EOS，**在該數值表的溫度與體積範圍之外所得的壓力並不準確**。請在 [狀態方程](../5-equation-of-states.md) 中確認 EOS 的出處與適用範圍。

## 其他問題 {#others}

### 回報錯誤時應提供哪些資訊？

請在 [GitHub Issues](https://github.com/seto77/PDIndexer/issues) 中附上下列內容回報。

- PDIndexer 的版本（`說明` ▸ `關於`）與 Windows 的版本
- 能重現問題、可以分享的最小檔案組（圖譜、晶體清單 `.xml`、IPAnalyzer 設定檔等）
- 您所執行的操作步驟，以及錯誤訊息或螢幕擷取畫面
- 您預期的結果（您認為正確的數值）
