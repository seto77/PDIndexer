# 繞射圖譜

本頁說明 PDIndexer 所處理的「圖譜資料」本身（測量資料集），以及如何載入、顯示與匯出。載入後的處理──平滑化、背景扣除等──則在 [圖譜參數](4-profile-parameter.md) 視窗中進行。支援的副檔名完整清單請參閱 [檔案格式](appendix/file-formats.md)。

![PDIndexer 主視窗，中央顯示圖譜，右側為圖譜清單與晶體清單。](../assets/cap-zh-Hant-auto/FormMain.png)

## 何謂圖譜

圖譜是粉末繞射測量所得到的一維「橫軸 vs. 強度」資料集。橫軸依測量幾何方式，以下列其中一種方式表示：

- 角度分散型繞射（一般 X 光繞射）為 \( 2\theta \)（繞射角）
- 能量分散型測量（白色 X 光、SSD 偵測）為能量
- 中子飛行時間（TOF）法為飛行時間
- 無論何種情形，資料在內部皆可轉換為晶面間距(d值) \( d \) 或散射向量 \( q \) 來處理

縱軸為繞射強度，可顯示為 `原始計數` 或 `每步計數 (CPS)`（即計數除以曝光時間（秒）），並可選擇線性或對數尺度（詳見 [主視窗](1-main-window.md) 頁面中的 `垂直軸`）。

## 支援的輸入格式

`檔案` ▸ `讀取輪廓檔` 可載入 PDIndexer 本身的格式，以及其他程式的輸出與通用文字格式。

| 副檔名 | 內容 |
| --- | --- |
| `pdi` / `pdi2` | PDIndexer 原生圖譜格式（包含軸設定與處理資訊） |
| `csv` | WinPIP 輸出（以逗號分隔） |
| `chi` | Fit2D 輸出 |
| `tsv` | 以定位點分隔的文字 |
| `ras` | Rigaku（RAS）格式 |
| `nxs` | NeXus 格式 |
| `npd` / `xbm` / `rpt`（`rpf`） | SSD（半導體偵測器）原始資料 |
| 其他文字 | 一般而言，任何兩欄的角度（或 d 值）－強度文字皆可讀取 |

!!! note "讀取通用文字"
    以角度－強度文字格式儲存的檔案，即使不屬於上述標準格式，通常也能讀取。若無法判斷橫軸類型或波長／能量，請在下述的 `資料轉換器` 對話方塊中指定。

各格式的詳細規格彙整於 [檔案格式](appendix/file-formats.md)。

## 載入方式

圖譜可透過下列幾種方式載入。

- **選單** — `檔案` ▸ `讀取輪廓檔`。可一次選取多個檔案。
- **拖放** — 從檔案總管將檔案拖放至主視窗。
- `監視剪貼簿` — 啟用 `選項` ▸ `監視剪貼簿` 後，會自動匯入從其他應用程式（例如 IPAnalyzer 或 CSManager）複製的圖譜／晶體。
- `監視檔案` — 啟用 `選項` ▸ `監視檔案`，並以 `設定要監視的目錄` 選擇資料夾後，該資料夾內新建立的 `pdi` 圖譜檔會自動讀入。這對連續測量時的即時顯示相當方便。

!!! tip "自動對齊橫軸"
    勾選 `讀取圖譜後，變更水平軸` 後，讀入新圖譜的當下即會將橫軸顯示切換為與該圖譜一致。

## 單一圖譜模式與多重圖譜模式

以主視窗右側的 `單一/多重圖譜` 切換顯示模式。

- `單一圖譜` — 載入新圖譜時會取代先前的資料，同一時間僅顯示一份圖譜。
- `多重圖譜` — 已載入的圖譜會重疊顯示。使用 `各圖譜間的強度位移` 可讓各圖譜的強度略微偏移，以便更容易區分多條曲線。啟用 `自動變更顏色` 會自動為每份圖譜指定繪圖顏色。

## 圖譜清單

主視窗右側的 `剖面` 清單會顯示所有已載入的圖譜。

- 只有勾選的圖譜才會繪製於中央檢視區。使用 `全部勾選/取消` 可一次切換全部勾選狀態。
- 點按 `顏色` 欄可變更各圖譜的繪圖顏色。
- 調整清單中項目的順序，可調整重疊繪圖的順序。
- 在單一圖譜模式下此清單會停用，於多重圖譜模式下則會顯示多份圖譜。

更詳細的圖譜設定（名稱、線型、平滑化、背景扣除、軸修正、圖譜運算等）可在勾選清單下方的 `剖面參數` 核取方塊後，於 [圖譜參數](4-profile-parameter.md) 視窗中進行。

## Data Converter 對話方塊

當載入無法判斷橫軸類型的通用文字檔，或 SSD（能量分散型）原始資料時，會開啟 `資料轉換器` 對話方塊，供你指定所讀入資料的橫軸及其相關參數。

![Data Converter 對話方塊，含橫軸設定、曝光時間與 EDX 選項。](../assets/cap-zh-Hant-auto/FormDataConverter.png)

此對話方塊可設定下列項目。

| 項目 | 內容 |
| --- | --- |
| 橫軸設定 | 指定資料的橫軸類型（X 光波長／能量、2θ、中子 TOF 長度／角度等）及對應的來源參數。 |
| `曝光時間 (每步)` | 每個資料步的曝光（測量）時間，單位為秒。用於 CPS 換算；小於等於 0 的值會視為 1。 |
| `解迴旋` | Kα2 去除功能已移至 [圖譜參數](4-profile-parameter.md) 表單。若要去除，請將 X 光源選為 Kα1。 |
| `SSD 資料用` 下的 `低能量截止` | 捨棄 EDX 能譜中低於右側閾值（eV）的低能量側部分。 |

當橫軸類型為能量分散型（白色 X 光、EDX）時，請輸入能量校正係數 `E = a₀ + a₁ n + a₂ n²`（E：能量，單位 eV；n：通道編號），以將通道編號轉換為能量。按一下 `確定` 套用設定並轉換資料，或按 `取消` 中止匯入。

## 匯出圖譜

- `檔案` ▸ `儲存輪廓檔` — 以 PDIndexer 原生的 `pdi2` 格式儲存所有已載入的圖譜，並保留軸設定與處理資訊。
- `檔案` ▸ `匯出選取的輪廓` — 以下列其中一種格式匯出圖譜：
  - `以 CSV（逗號分隔值）檔` — 將已勾選的圖譜以逗號分隔值（X, Y）儲存，可合併為一個檔案，也可每個圖譜各存成一個檔案。選擇儲存位置後，回答 `是` 即合併，回答 `否` 則分別儲存。X 為目前顯示的水平軸座標。無論地區設定為何，小數點一律使用 `.`。
  - `以 TSV（定位點分隔值）檔` — 以定位點分隔儲存相同的內容。
  - `以 GSAS 檔` — 將所選取的圖譜以 GSAS（Rietveld）資料格式寫出。僅當水平軸為 2θ 或中子 TOF 時才能匯出。

!!! note "儲存圖形"
    若要儲存繪製出的圖形而非圖譜資料，請使用 `檔案` ▸ `複製到剪貼簿` 或 `檔案` ▸ `另存為中繼檔`（EMF）。EMF 是一種可匯入 PowerPoint 與 Word 的向量格式。
