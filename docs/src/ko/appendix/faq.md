# Q&A

이 페이지에는 사용자가 실제로 문의한 질문 가운데 자주 묻는 것과 오해하기 쉬운 점을 중심으로 모았습니다. 오류나 시작 문제에 대해서는 [문제 해결](troubleshooting.md)도 참조하십시오.

## 먼저 시도할 것 {#first-steps}

### 상태가 이상합니다(회절선이 나타나지 않음, 파일을 읽을 수 없음, 시작 시 오류). 먼저 무엇을 해 보면 됩니까?

먼저 이 페이지에서 증상에 해당하는 항목을 찾으십시오. 회절선이 나타나지 않는 경우, 원인은 거의 항상 방사선 종류나 파장 설정입니다([회절선과 결정 목록](#peaks-and-crystals)). 그래도 해결되지 않으면 다음 순서로 시도하십시오.

1. 최신 버전으로 업데이트합니다(`도움말` ▸ `프로그램 업데이트`, 또는 [릴리스 페이지](https://github.com/seto77/PDIndexer/releases/latest)에서 다운로드).
2. `옵션` ▸ `레지스트리 지우기 (체크 후 재시작)`에 체크한 다음 PDIndexer를 종료하고 다시 시작합니다. PDIndexer는 창 위치, 빔 설정 등을 레지스트리에 저장하는데, 이전 버전에서 이어받은 설정이 문제를 일으킬 수 있습니다.
3. 결정 목록이 이상해 보이면 `파일` ▸ `결정을 초기 상태로 되돌리기`를 실행합니다.

!!! warning "사라지는 것"
    - **레지스트리를 지우면** 저장된 설정과 **매크로 창에 등록한 매크로**가 삭제됩니다. 필요한 매크로는 미리 `.mcr` 파일로 내보내 두십시오. 결정 목록은 레지스트리가 아니라 별도의 파일(`%APPDATA%\PDIndexer\PDIndexer\default.xml`)에 저장되므로, 레지스트리를 지워도 삭제되지 않습니다.
    - **결정 목록을 되돌리면** 직접 추가하거나 편집한 결정이 사라집니다. 필요한 결정은 먼저 `파일` ▸ `결정 저장`으로 저장해 두십시오.

### PDIndexer를 IPAnalyzer와 함께 사용하면 오류가 나거나 값이 이상합니다.

[IPAnalyzer](https://github.com/seto77/IPAnalyzer)와 PDIndexer는 공통 라이브러리를 사용하며 클립보드를 통해 데이터를 주고받습니다. 한쪽만 업데이트하면 주고받는 형식이 맞지 않아 오류나 잘못된 값이 생길 수 있습니다. **두 프로그램을 함께 최신 상태로 유지하십시오.**

## 설치와 시작 {#install}

### 관리자 권한이 없는 PC에 PDIndexer를 설치할 수 없거나, 정책 때문에 MSI가 차단됩니다.

**no-install ZIP 패키지**(x64용 `PDIndexer-v.<ver>.zip`, Arm64용 `PDIndexer-v.<ver>_arm64.zip`)를 사용하십시오. 런타임이 포함되어 있으므로 MSI도, 별도의 .NET Desktop Runtime도 필요하지 않습니다. 폴더 전체를 쓰기 가능한 위치에 압축 해제하고, 압축을 푼 폴더 안의 `PDIndexer.exe`를 실행하십시오. PDIndexer 자체는 일반 사용자 권한으로 실행됩니다.

MSI 패키지와 ZIP 패키지의 차이는 [실행 환경 및 설치](runtime-and-installation.md)를 참조하십시오.

!!! note
    PDIndexer는 서명되지 않은 연구용 소프트웨어이므로, 다운로드하거나 처음 실행할 때 Windows(SmartScreen) 또는 브라우저가 경고를 표시할 수 있습니다. 브라우저의 다운로드 목록에서는 **자세히** ▸ **유지**를, 실행 시 경고에서는 **추가 정보** ▸ **실행**을 선택하십시오.

### .NET을 설치했는데도 "You must install .NET Desktop Runtime"이라고 표시됩니다.

원인은 대개 다음 중 하나입니다.

- **주 버전이 다릅니다.** PDIndexer에 필요한 .NET 버전은 PDIndexer 버전에 따라 달라집니다. 사용하는 릴리스에 명시된 버전의 **Desktop Runtime**을 설치하십시오. 일반 ".NET Runtime"만으로는 부족합니다.
- **아키텍처가 다릅니다.** x64 빌드의 PDIndexer에는 x64 런타임이, Arm64 빌드에는 Arm64 런타임이 필요합니다. Arm 기반 Windows(Snapdragon PC 등)에서는 Arm64 설치 프로그램 `PDIndexer-setup_arm64.msi`를 사용하십시오.
- 그래도 해결되지 않으면 런타임이 포함된 **no-install ZIP 패키지**가 가장 확실한 방법입니다.

## 회절선과 결정 목록 {#peaks-and-crystals}

### 결정을 체크해도 회절선이 나타나지 않거나, 크게 어긋나 있습니다.

먼저 다음을 확인하십시오.

- [`프로파일 위에 피크 표시`](../3-crystal-parameter.md)가 켜져 있고, 결정 목록에서 해당 결정이 체크되어 있는지.
- **측정에 사용한 방사선 종류와 파장(또는 에너지)이 올바르게 설정되어 있는지.** CSV 등의 텍스트 데이터에는 파장 정보가 없는 경우가 많습니다. 이 경우 파일을 읽을 때 표시되는 대화 상자에서 측정에 사용한 방사선 종류와 파장을 지정하십시오. 표시에 사용하는 방사선 종류와 파장은 메인 창의 [`가로축` 탭](../1-main-window.md#horizontal-axis-tab)에서 확인하십시오.
- 회절선이 그리기 범위 밖에 있지 않은지. 가로축 범위를 넓혀 보십시오(특히 중성자 TOF).
- 특정 결정만 나타나지 않는다면, 그 결정의 격자 상수와 원자 위치가 크게 어긋나 있지 않은지 확인하고, 내장 데이터베이스의 같은 물질과 비교해 보십시오.

### 회절선을 드래그했더니 격자 상수가 바뀌었습니다. 재시작해도 원래대로 돌아오지 않습니다.

`옵션` ▸ `닫을 때 결정 목록 저장`이 기본적으로 켜져 있으므로, 회절선을 드래그하여 바뀐 격자 상수는 PDIndexer를 종료할 때 저장됩니다. 따라서 재시작해도 변경이 취소되지 않습니다.

- 현재 세션에서 결정을 불러왔을 때의 격자 상수로 되돌리려면, 결정 정보에서 마우스 오른쪽 버튼을 클릭하고 `격자 상수 되돌리기`를 선택하십시오.
- 결정 목록 전체를 설치 직후의 상태로 되돌리려면 `파일` ▸ `결정을 초기 상태로 되돌리기`를 선택하십시오.

### 결정 목록에 이상한 값이나 중복이 있거나, 압력 표준(Au, Pt 등)이 없습니다.

`파일` ▸ `결정을 초기 상태로 되돌리기`를 실행하면 압력 표준을 포함한 초기 결정 목록이 복원됩니다. 직접 추가한 결정은 사라지므로 필요하면 먼저 저장하십시오.

### 강도비가 계산되지 않고 모든 회절선의 높이가 같습니다.

강도비를 계산하려면 결정에 원자 위치가 있어야 하고, [`강도 비율 계산`](../3-crystal-parameter.md)이 켜져 있어야 합니다. 방사선 설정이 잘못되어 있어도 강도가 올바르지 않게 됩니다. 자세한 내용은 [문제 해결](troubleshooting.md)을 참조하십시오.

### CSManager나 CIF 파일에서 결정을 가져오려면 어떻게 합니까?

- **CSManager에서**: 먼저 PDIndexer의 `결정 파라미터` 창을 열고 `옵션` ▸ `클립보드 감시`를 켠 다음, CSManager에서 결정을 선택하십시오. 미리 CIF로 내보낼 필요는 없습니다.
- **CIF / AMC 파일**은 결정 파라미터 창의 결정 정보 영역에 끌어다 놓을 수 있습니다.
- **내장 결정 데이터베이스**(AMCSD)에서 검색할 수도 있습니다. [결정 파라미터](../3-crystal-parameter.md)를 참조하십시오.

어느 방법이든 결정은 결정 정보 영역에 표시됩니다. 결정 목록에 남기려면 `추가`를 누르십시오.

### X선 데이터와 전자선(또는 다른 파장) 데이터를 같은 가로축에 겹쳐 표시할 수 있습니까?

예. PDIndexer에는 가로축이 하나뿐이며, 읽어들인 모든 프로파일은 `가로축` 탭에서 선택한 방사선 종류와 파장으로 환산됩니다. 예를 들어 전자 회절 프로파일을 Cu Kα의 2θ 눈금으로 표시할 수 있습니다.

`가로축` 탭의 `프로파일을 읽은 후 가로축 변경`이 켜져 있으면, 새 파일을 읽을 때마다 축 설정이 그 파일의 설정으로 바뀝니다. 비교를 위해 축을 고정하려면 이 옵션을 끄십시오.

## 프로파일 읽기와 가로축 {#profiles-and-axis}

### 메인 창의 `가로축` 탭과 프로파일 파라미터 창의 `축 설정`은 무엇이 다릅니까?

- **`가로축` 탭**(메인 창)은 **데이터를 어떻게 표시할지**만 정합니다. 프로파일 데이터 자체는 바뀌지 않습니다.
- **[`축 설정`](../4-profile-parameter.md#axis-setting)**(프로파일 파라미터 창)은 **프로파일을 측정한 조건**(방사선 종류, 파장, 취출각 등)을 다시 씁니다. 파일을 읽을 때 방사선 종류나 파장을 잘못 선택했다면 여기에서 바로잡으십시오. 값을 잘못된 **단위**로 입력했다면 원본 파일을 다시 읽으십시오.

### 에너지 분산(백색 X선) 데이터(`.npd` / `.nxs`)의 가로축이 이상하거나 회절선이 나타나지 않습니다.

파일을 읽을 때 표시되는 대화 상자에서 **에너지 단위(eV / keV)**, **2θ**, 그리고 `.nxs`의 경우 **채널–에너지 교정 계수**가 측정과 일치하는지 확인하십시오. `.npd` 파일은 파일 안의 에너지 열을 사용하므로, 원본 파일의 값과 단위도 확인하십시오. 단위가 틀리면 피크 위치가 크게 어긋납니다.

### GSAS `.gsa` 파일(2θ가 센티도 단위)이나 q(파수) 축의 데이터를 읽을 수 있습니까?

예.

- `.gsa` 파일(공백으로 구분된 3열, 2θ는 센티도 단위)은 데이터 변환 대화 상자에서 가로축으로 2θ를, 단위로 센티도(centi-degree)를 선택하십시오.
- q(파수) 축의 데이터는 가로축으로 q를 선택하십시오. q 축에서 격자 상수를 정밀화할 수도 있습니다.

## 피크 피팅과 격자 상수 {#fitting}

### `검색 범위`는 어느 정도로 하면 됩니까? 바꾸면 부피가 달라집니다.

`검색 범위`는 피크 중심 양쪽의 탐색 폭입니다. 피크 **반치전폭(FWHM)의 2–3배**에서 시작하고, 이웃 피크와 겹치면 좁히십시오. 범위가 너무 넓으면 다른 피크나 배경이 섞이고, 너무 좁으면 피크의 꼬리가 잘립니다. 어느 쪽이든 피팅 위치가 어긋납니다. **고각 피크**를 많이 사용하면 격자 상수의 정밀도가 높아집니다.

### `최적화한 격자 상수`에 표시된 값은 이미 결정에 적용된 것입니까?

아니요. `최적화한 격자 상수`는 선택한 반사와 피팅 조건으로부터 얻은 값을 **표시**할 뿐입니다. 결정의 격자 상수를 덮어쓰려면 `선택한 결정에 적용`을 누르십시오. 결정을 바꾸지 않고 값만 사용하려면 `클립보드에 복사`를 사용하십시오. `선택한 결정에 적용`을 몇 번 누르면 계산된 회절선 위치가 매번 갱신되므로 수렴에 도움이 될 수 있습니다.

### 같은 반사를 선택했는데 부피의 오차가 갑자기 커졌습니다.

피크 피팅(각 피크에 함수를 맞추는 것)과 격자 상수 정밀화는 별개의 계산입니다. PDIndexer는 각 반사의 검색 범위 안에서만 피크를 찾으므로, 다른 상의 피크나 노이즈가 범위 안에 들어오면 잘못된 d 값이 격자 상수 계산에 들어갑니다.

- 반사 목록에서 각 반사의 피팅 상태를 확인하고, 의심스럽거나 약한 피크는 제외하십시오.
- 신호 대 잡음비가 나쁠 때는 먼저 강한 피크만으로 정밀화한 다음 약한 피크를 추가하십시오. 결정계의 독립적인 격자 상수 수(입방정계는 1, 삼사정계는 6) 이상의 독립적인 반사가 필요하며, 오차를 추정하려면 그보다 많이 필요합니다.
- 약하거나 겹침이 심한 패턴에는 리트벨트 해석 등의 전체 패턴 피팅이 더 적합할 수 있습니다.

격자 상수와 그 오차의 계산 방법은 [알고리즘 해설](algorithms.md#lattice-refinement)을 참조하십시오.

## 연속 분석과 매크로 {#sequential-and-macro}

### 많은 프로파일(시간 분해, 압력 단계 등)을 자동으로 피팅하여 격자 상수나 압력을 구하고 싶습니다.

[연속 분석](../7-sequential-analysis.md)을 사용하십시오(메인 창의 도구 모음 또는 `Ctrl+Shift+S`로 엽니다). 실행하기 전에 **피크 피팅 창을 열고** 결정과 반사를 선택하십시오. 프로파일이 4개 이상 필요합니다. 결과는 자동으로 저장할 수 있습니다.

- 수천 개의 프로파일을 한 번에 읽으면 메모리를 많이 사용합니다. 먼저 100개 정도로 조건을 정한 다음 전체를 실행하십시오.
- 네트워크 폴더에서 직접 읽으면 느립니다. 분석 전에 파일을 로컬 디스크로 복사하십시오.
- 시리즈 도중 격자 상수가 크게 변하면 피크가 검색 범위를 벗어나 다른 피크를 잡을 수 있습니다. `허용 계수`를 켜면 **실행 시작 시의 부피**와 설정값(%) 이상 차이 나는 점은 NaN으로 출력됩니다.

### 연속 분석으로 여러 상(예: 시료와 압력 마커)을 동시에 피팅할 수 있습니까?

체크된 모든 결정의 피크가 피팅됩니다(피크 분리를 `결정 간`으로 설정하면 서로 다른 상의 겹친 피크도 함께 분리됩니다). 다만 한 번의 연속 분석에서 격자 상수와 압력이 기록되는 것은 피크 피팅 창에서 선택한 결정 하나뿐입니다. 다른 상의 결과를 얻으려면 그 결정을 선택하고 다시 실행하거나, 결정을 전환하는 [매크로](../8-macro.md)를 사용하십시오.

### 방위각별로 나눈 프로파일로 응력 분석을 실행했는데 `Singh의 식` 탭이 비어 있습니다.

응력 분석 모드는 **프로파일 목록의 첫 번째 프로파일 이름이 `whole`로 끝날 때**에만 선택됩니다. 두 번째 이후의 프로파일은 이름의 **마지막 하이픈 뒤**의 텍스트를 방위각(도)으로 읽습니다(예: `sample-30`). 또한 프로파일이 4개 이상 읽어들여져 있는지, 피크 피팅 창이 열려 있는지도 확인하십시오. 일반 실행(응력 모드가 아닌 경우)에서는 `Singh의 식` 탭이 비어 있습니다. 자세한 내용은 [연속 분석](../7-sequential-analysis.md)을 참조하십시오.

### 소수점 구분 기호가 쉼표이면 연속 분석 CSV의 열이 어긋납니다.

연속 분석 CSV는 화면에 표시된 숫자를 그대로 사용하므로, 소수점 구분 기호가 쉼표(`1,5`)이면 소수점과 열 구분 기호를 구별할 수 없습니다. 당분간은 결과 탭의 `복사`로 표를 탭 구분 텍스트로 복사하여, 스프레드시트에 탭 구분 데이터로 붙여 넣으십시오. 프로파일 자체의 CSV 내보내기(`파일` ▸ `선택한 프로파일 내보내기`)는 지역 설정과 관계없이 항상 `.`를 소수점 구분 기호로 씁니다.

### 매크로는 어떤 언어로 작성합니까? 파일 경로는 어떻게 써야 합니까?

매크로는 **Python(IronPython)**으로 작성합니다. Windows 경로는 슬래시(`'C:/data/sample.pdi2'`)로 쓰거나 raw 문자열(`r'C:\data\sample.pdi2'`)로 쓰십시오. 사용할 수 있는 함수는 [매크로](../8-macro.md)의 함수 참조에 나와 있습니다.

## 상태 방정식 {#eos}

### 온도를 입력했습니다. 결과를 고온에서의 압력으로 보아도 됩니까?

일부 상태 방정식(EOS)은 원 논문에 온도 항이 없으며(등온 식), 입력한 온도가 사용되지 않습니다. 문헌의 수치표를 보간하는 EOS는 **표의 온도·부피 범위를 벗어나면 정확하지 않은 압력**을 줍니다. [상태 방정식](../5-equation-of-states.md)에서 EOS의 출처와 적용 범위를 확인하십시오.
