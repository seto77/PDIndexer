# Q&A

利用者から実際に寄せられた質問のうち、よくあるもの・勘違いしやすいものをまとめました。エラーが出る、起動しないといった不具合への対処は [トラブルシューティング](troubleshooting.md) も参照してください。

## 困ったときに最初に試すこと {#first-steps}

### 動作がおかしい（回折線が出ない、ファイルが読めない、起動時にエラーが出る）。まず何を試せばよいですか？

まず、このページで症状に合う項目を確かめてください。回折線が出ない場合は、線源や波長の設定の誤りがほとんどです（[回折線が表示されない](#peaks-and-crystals)）。それでも直らない場合は、次の順に試します。

1. 最新版に更新します（`ヘルプ` ▸ `アップデートをチェック`、または [リリースページ](https://github.com/seto77/PDIndexer/releases/latest) から入手）。
2. `オプション` ▸ `レジストリを消去 (チェックして再起動)` にチェックを入れ、PDIndexer を終了してから起動し直します。PDIndexer はウィンドウの位置や線源の設定などをレジストリに保存しており、古い版から引き継いだ設定が原因になることがあります。
3. 結晶リストがおかしい場合は、`ファイル` ▸ `結晶リストをインストール直後の状態に戻す` を実行します。

!!! warning "消えるもの"
    - **レジストリの消去** では、保存されている設定と、**マクロ画面に登録したマクロ** が消えます。必要なマクロは、先に `.mcr` ファイルとして書き出してください。結晶リストはレジストリではなく別のファイル（`%APPDATA%\PDIndexer\PDIndexer\default.xml`）に保存されているので、レジストリの消去では消えません。
    - **結晶リストを初期状態に戻す** と、自分で追加・編集した結晶は失われます。必要な結晶は、先に `ファイル` ▸ `結晶リストを保存` で書き出してください。

### IPAnalyzer と一緒に使うと、エラーが出たり値がおかしくなったりします。

[IPAnalyzer](https://github.com/seto77/IPAnalyzer) と PDIndexer は共通のライブラリを使い、クリップボード経由でデータを受け渡しています。片方だけを更新すると、受け渡しの形式が合わずにエラーや誤った値が出ることがあります。**両方を同じ時期の最新版にそろえて** ください。

## インストールと起動 {#install}

### 管理者権限がない PC や、ポリシーで MSI が止められる PC にインストールできません。

**no-install ZIP 版**（x64 は `PDIndexer-v.<ver>.zip`、Arm64 は `PDIndexer-v.<ver>_arm64.zip`）を使ってください。ZIP にはランタイムが同梱されているので、MSI の実行や .NET Desktop Runtime のインストールは要りません。フォルダー全体をユーザーが書き込める場所に展開し、展開したフォルダー内の `PDIndexer.exe` を実行します。PDIndexer 本体は一般ユーザーの権限で動きます。

MSI 版と ZIP 版の違いや手順は [動作環境とインストール](runtime-and-installation.md) を参照してください。

!!! note
    PDIndexer は署名のない研究用ソフトウェアなので、ダウンロードや初回の実行時に Windows (SmartScreen) やブラウザーが警告を出すことがあります。ブラウザーのダウンロード一覧では **詳細情報** ▸ **保持**、実行時の警告では **詳細情報** ▸ **実行** を選ぶと先に進めます。

### 「.NET Desktop Runtime をインストールしてください」と表示されます。.NET は入れたはずなのですが。

次のどれかが原因のことが多いです。

- **必要なメジャーバージョンが違う。** PDIndexer の版によって必要な .NET のバージョンが変わります。使うリリースに書かれたバージョンの **デスクトップ ランタイム** を入れてください。「.NET ランタイム」だけでは起動しません。
- **アーキテクチャが違う。** x64 版の PDIndexer には x64 版のランタイム、Arm64 版には Arm64 版のランタイムが要ります。Arm 版の Windows（Snapdragon PC など）では、Arm64 版の `PDIndexer-setup_arm64.msi` を使ってください。
- どうしても合わない場合は、ランタイム同梱の **no-install ZIP 版** を使うのが確実です。

## 回折線の表示と結晶リスト {#peaks-and-crystals}

### 結晶にチェックを入れても回折線が表示されない、または位置が大きくずれます。

まず次を確かめてください。

- [`回折線を重ねて表示`](../3-crystal-parameter.md) (Show peaks over profiles) がオンで、結晶リストでその結晶にチェックが入っているか。
- **測定の線源・波長（またはエネルギー）が正しく指定されているか。** CSV などのテキストデータには波長の情報が入っていないことが多く、その場合は読み込み時のダイアログで、測定に使った線源・波長を指定します。表示に使う線源・波長は、メインウィンドウの [`横軸` タブ](../1-main-window.md#horizontal-axis) で確かめます。
- 回折線が描画範囲の外にないか。横軸の範囲を広げてみてください（中性子 TOF では特に）。
- 特定の結晶だけ表示されない場合は、格子定数や原子位置の入力が大きく外れていないか確かめ、内蔵データベースの同じ物質と比べてください。

### 回折線をドラッグして変わった格子定数を元に戻したい。再起動しても戻りません。

回折線のドラッグで変えた格子定数は、`オプション` ▸ `終了時に結晶リストを自動保存する`（既定でオン）により終了時に保存されるので、再起動しても元に戻りません。

- 今回の起動で結晶を読み込んだときの格子定数に戻すには、結晶情報の上で右クリックし、`読み込み時の格子定数に戻す` を選びます。
- 結晶リスト全体をインストール直後の状態に戻すには、`ファイル` ▸ `結晶リストをインストール直後の状態に戻す` を選びます。

### 結晶リストに変な値が入った、同じ結晶が重複した、圧力標準（Au、Pt など）が見当たりません。

`ファイル` ▸ `結晶リストをインストール直後の状態に戻す` で、圧力標準を含む初期の結晶リストに戻せます。自分で追加した結晶は失われるので、必要なら先に保存しておいてください。

### 強度比が計算されず、すべて同じ高さで表示されます。

強度比を計算するには、結晶に原子位置が入力されていて、[`強度比を計算` (Calculate intensity ratio)](../3-crystal-parameter.md) がオンになっている必要があります。線源の設定が誤っていても、正しい強度は出ません。詳しくは [トラブルシューティング](troubleshooting.md) を参照してください。

### CSManager の結晶や CIF ファイルを取り込むには？

- **CSManager から送る場合**: 先に PDIndexer の `回折線/結晶情報` ウィンドウを開き、`オプション` ▸ `クリップボードを監視` をオンにしてから、CSManager で結晶を選びます。CIF に書き出してから開く必要はありません。
- **CIF / AMC ファイル** は、回折線・結晶情報ウィンドウの結晶情報の欄へドラッグ＆ドロップすると読み込めます。
- **内蔵の結晶データベース**（AMCSD）からも検索できます。詳しくは [回折線・結晶情報](../3-crystal-parameter.md) を参照してください。

どの方法でも、結晶は結晶情報の欄に表示されます。結晶リストに残すには `追加` を押してください。

### X 線のデータと電子線（または別の波長）のデータを、同じ横軸で重ねて比べられますか？

比べられます。PDIndexer の横軸は 1 つで、読み込んだプロファイルはすべて、`横軸` タブで選んだ線源・波長の横軸に換算して表示されます。たとえば電子回折のプロファイルを Cu Kα の 2θ で表示できます。

`横軸` タブの `横軸を最後に読み込んだプロファイルのものにそろえる` がオンだと、プロファイルを読み込むたびに横軸の設定がそのファイルのものに切り替わります。比べる横軸を固定したいときは、このチェックを外してください。

## プロファイルの読み込みと横軸 {#profiles-and-axis}

### メイン画面の `横軸` タブと、プロファイル情報の `軸変換` は何が違いますか？

- **`横軸` タブ**（メインウィンドウ）は **表示のしかた** を決めるだけで、プロファイルのデータそのものは変わりません。
- **[`軸変換` (Axis setting)](../4-profile-parameter.md#axis-setting)**（プロファイル情報ウィンドウ）は、**そのプロファイルを測定した条件**（線源の種類・波長・取り出し角など）を書き換えます。読み込み時に線源や波長を間違えたときは、こちらで直します。入力した数値の **単位** を取り違えた場合は、元のファイルを読み込み直してください。

### エネルギー分散型（白色 X 線）のデータ（`.npd` / `.nxs`）の横軸がおかしい、回折線が出ません。

読み込み時に表示されるダイアログで、**エネルギーの単位（eV / keV）**、**2θ**、`.nxs` では **チャンネル→エネルギーの校正係数** が測定条件どおりかを確かめてください。`.npd` はファイル内のエネルギーの列を使うので、元ファイルの値と単位も確かめます。単位を取り違えると、ピーク位置が大きくずれます。

### GSAS の `.gsa`（2θ がセンチ度）や、q（波数）軸のデータを読み込めますか？

読み込めます。

- `.gsa`（空白区切り 3 列、2θ がセンチ度のもの）は、データ変換のダイアログで横軸を 2θ、単位をセンチ度（centi-degree）にして読み込みます。
- q（波数）軸のデータは、横軸を q にして読み込みます。q 軸のまま格子定数を精密化することもできます。

## ピークフィッティングと格子定数 {#fitting}

### `範囲` (Search Range) はいくつにすればよいですか？ 値を変えると体積が変わります。

`範囲` はピークの中心から片側への探索幅です。**ピークの半値幅（FWHM）の 2〜3 倍** を出発点にし、隣のピークと重なる場合は狭くしてください。範囲が広すぎると別のピークやバックグラウンドを拾い、狭すぎるとピークの裾が切れて、どちらも位置がずれます。格子定数の精度を上げるには、**高角側のピーク** を多く使うのが有効です。

### `最適化した格子定数` に表示された値は、もう結晶に反映されていますか？

反映されていません。`最適化した格子定数` は、選んだ反射とフィッティングの条件から求めた値を **表示しているだけ** です。結晶の格子定数を書き換えるには `選択中の結晶に適用` を押します。結晶を変えずに値だけ使いたい場合は `クリップボードにコピー` を使います。`選択中の結晶に適用` を何回か押すと、回折線の位置が更新されて収束が進むことがあります。

### 同じ反射を選んでいるのに、体積の誤差が急に大きくなります。

ピークのフィッティング（関数の当てはめ）と、格子定数の精密化は別の計算です。PDIndexer は各反射の探索範囲の中でピークを探すだけなので、探索範囲に別の相のピークやノイズが入ると、間違った d 値が格子定数の計算に入ります。

- 回折線リストで各反射のフィット結果を確かめ、怪しいピークや弱いピークは外してください。
- S/N が悪いときは、まず強いピークだけで精密化し、あとから弱いピークを足すと安定します。ただし、結晶系の独立な格子定数の数（立方晶は 1、三斜晶は 6）以上の独立な反射が要ります。誤差を見積もるには、それより多くの反射が必要です。
- 弱いピークや重なりの多いパターンでは、Rietveld 解析など全パターンのフィッティングの方が適していることがあります。

格子定数と誤差の計算方法は [アルゴリズム解説](algorithms.md#lattice-refinement) を参照してください。

## 連続分析とマクロ {#sequential-and-macro}

### 多数のプロファイル（時分割・圧力ステップなど）を自動でフィットして、格子定数や圧力を出したい。

[連続分析](../7-sequential-analysis.md) を使います（メインウィンドウのツールバー、または `Ctrl+Shift+S` で開きます）。**ピークフィッティングのウィンドウを開き**、解析する結晶と反射を選んでから実行します。プロファイルは 4 本以上必要です。結果は自動保存できます。

- 何千ものプロファイルを一度に読むとメモリーを圧迫するので、まず 100 本程度で条件を決めてから全体を流してください。
- ネットワーク上のフォルダーから直接読むと遅いので、ローカルのディスクにコピーしてから解析してください。
- 途中で格子定数が大きく変わると、ピークが探索範囲から外れて別のピークを拾うことがあります。`許容係数` をオンにすると、**解析を始めたときの体積** からの変化が設定値（%）を超えた点は NaN として出力されます。

### 連続分析で、複数の相（試料と圧力マーカーなど）を同時にフィットできますか？

チェックした複数の結晶のピークは、一緒にフィットされます。ただし、1 回の連続分析で格子定数や圧力を記録するのは、フィッティングのウィンドウで選んでいる 1 つの結晶だけです。別の相の結果がほしい場合は、選ぶ結晶を替えてもう一度実行するか、[マクロ](../8-macro.md) で結晶を切り替えながら処理してください。

### 方位角ごとに分けたプロファイルで応力解析をしたのに、`Singh` タブが空です。

応力解析のモードになるのは、プロファイルリストの **先頭のプロファイルの名前が `whole` で終わる** ときだけです。2 本目以降は、名前の **最後のハイフンより後** が方位角（度）として読まれます（例: `sample-30`）。このほか、プロファイルが 4 本以上あること、フィッティングのウィンドウが開いていることも確かめてください。応力モードでない通常の実行では、`Singh` タブは空になります。詳しくは [連続分析](../7-sequential-analysis.md) を参照してください。

### 小数点がカンマの地域設定で、連続分析の CSV を開くと列がずれます。

連続分析の CSV は、画面に表示した数値をそのまま使うため、小数点がカンマ（`1,5`）の地域設定では列の区切りと区別できなくなります。当面は、結果のタブの `コピー` でタブ区切りのテキストとしてコピーし、表計算ソフトにタブ区切りとして貼り付けてください。プロファイルそのものの CSV 出力（`ファイル` ▸ `プロファイルをエクスポート(csv)`）は、地域設定によらず小数点を `.` で書き出します。

### マクロはどの言語で書きますか？ ファイルのパスはどう書けばよいですか？

マクロは **Python（IronPython）** の書式で書きます。Windows のパスは、スラッシュ区切り（`'C:/data/sample.pdi2'`）にするか、raw 文字列（`r'C:\data\sample.pdi2'`）にしてください。使える関数は [マクロ](../8-macro.md) の関数リファレンスにあります。

## 状態方程式 {#eos}

### 温度を入力しましたが、高温での圧力として正しいですか？

状態方程式（EOS）によっては、元の文献に温度の項がなく、温度を入力しても計算に使われないもの（等温の式）があります。また、文献の表を補間している EOS では、**表の範囲外の温度・体積では圧力が不正確** になります。使う EOS の出典と適用範囲を [状態方程式](../5-equation-of-states.md) で確かめてください。

## その他 {#others}

### 不具合を報告するときは、何を送ればよいですか？

[GitHub の Issue](https://github.com/seto77/PDIndexer/issues) に、次のものを添えて報告してください。

- PDIndexer のバージョン（`ヘルプ` ▸ `PDIndexerについて`）と Windows のバージョン
- 症状を再現できる、公開してよい最小限のファイル（プロファイル、結晶リストの `.xml`、IPAnalyzer の設定ファイルなど）
- 操作の手順と、表示されたエラーメッセージやスクリーンショット
- 期待していた結果（正しいと考える値）

### PDIndexer をビームラインや研究室の Web ページで紹介・再配布してもよいですか？

構いません。PDIndexer は [MIT ライセンス](https://github.com/seto77/PDIndexer/blob/master/LICENSE.md) で配布しています。再配布するときは、著作権表示とライセンス文を添えてください。
