# Q&A

本页收集了用户实际提出过的问题，重点是常见问题和容易误解的地方。关于错误和启动问题，另请参见 [故障排除](troubleshooting.md)。

## 首先尝试的操作 {#first-steps}

### 出现异常（不显示衍射线、无法读取文件、启动时出错）。首先应尝试什么？

请先在本页中查找与症状相符的条目。不显示衍射线时，原因几乎总是入射线种类或波长的设置（[衍射线与晶体列表](#peaks-and-crystals)）。如果仍未解决，请按以下顺序尝试。

1. 更新到最新版本（`帮助` ▸ `检查更新`，或从 [发布页面](https://github.com/seto77/PDIndexer/releases/latest) 下载）。
2. 勾选 `选项` ▸ `清除注册表（勾选并重启）`，然后退出并重新启动 PDIndexer。PDIndexer 会将窗口位置、入射线设置等保存在注册表中，从旧版本继承的设置可能会引发问题。
3. 如果晶体列表看起来不正常，请执行 `文件` ▸ `将晶体恢复到初始状态`。

!!! warning "会丢失的内容"
    - **清除注册表** 会删除已保存的设置以及 **在宏窗口中注册的宏**。请事先将需要的宏导出为 `.mcr` 文件。晶体列表并不保存在注册表中，而是保存在另一个文件（`%APPDATA%\PDIndexer\PDIndexer\default.xml`）中，因此清除注册表不会删除它。
    - **恢复晶体列表** 会丢弃你添加或编辑过的晶体。请事先用 `文件` ▸ `保存晶体` 保存需要的晶体。

### 将 PDIndexer 与 IPAnalyzer 一起使用时，出现错误或数值不正确。

[IPAnalyzer](https://github.com/seto77/IPAnalyzer) 与 PDIndexer 共用一个通用库，并通过剪贴板交换数据。如果只更新了其中一个，交换格式可能不一致，从而导致错误或数值不正确。**请同时将两者都更新到最新版本。**

## 安装与启动 {#install}

### 无法在没有管理员权限的 PC 上安装 PDIndexer，或策略阻止了 MSI。

请使用 **免安装 ZIP 包**（x64 为 `PDIndexer-v.<ver>.zip`，Arm64 为 `PDIndexer-v.<ver>_arm64.zip`）。它自带运行时，因此既不需要 MSI，也不需要另外安装 .NET Desktop Runtime。将整个文件夹解压到可写入的位置，然后运行解压后文件夹中的 `PDIndexer.exe`。PDIndexer 本身以普通用户权限运行。

MSI 包与 ZIP 包的区别请参见 [运行环境与安装](runtime-and-installation.md)。

!!! note
    PDIndexer 是未签名的研究用软件，因此在下载或首次运行时，Windows（SmartScreen）或浏览器可能会发出警告。在浏览器的下载列表中选择 **更多信息** ▸ **保留**；在运行时的警告中选择 **更多信息** ▸ **仍要运行**。

### 明明已经安装了 .NET，却提示“You must install .NET Desktop Runtime”。

原因通常是以下之一。

- **主版本不对。** PDIndexer 所需的 .NET 版本会随 PDIndexer 版本而变化。请安装所用版本注明的版本的 **Desktop Runtime**。仅安装普通的“.NET Runtime”是不够的。
- **体系结构不对。** x64 版 PDIndexer 需要 x64 运行时；Arm64 版需要 Arm64 运行时。在基于 Arm 的 Windows（Snapdragon PC 等）上，请使用 Arm64 安装程序 `PDIndexer-setup_arm64.msi`。
- 如果仍然无法运行，自带运行时的 **免安装 ZIP 包** 是最可靠的选择。

## 衍射线与晶体列表 {#peaks-and-crystals}

### 勾选了晶体，但不显示衍射线，或衍射线位置偏差很大。

请先检查以下各项。

- [`在谱线上方显示衍射峰`](../3-crystal-parameter.md) 已开启，并且该晶体在晶体列表中已勾选。
- **测量时的入射线种类和波长（或能量）设置正确。** CSV 等文本数据往往不含波长信息；这种情况下，请在读取文件时显示的对话框中指定测量所用的入射线种类和波长。用于显示的入射线种类和波长可在主窗口的 [`横轴` 选项卡](../1-main-window.md#horizontal-axis-tab) 中确认。
- 衍射线不在绘图范围之外。请尝试扩大横轴范围（尤其是中子 TOF）。
- 如果只有某一种晶体不显示，请检查其晶格常数和原子位置是否偏差很大，并与内置数据库中的同一物质进行比较。

### 拖动衍射线后晶格常数改变了，重新启动也无法恢复。

由于 `选项` ▸ `关闭时保存晶体列表` 默认处于开启状态，拖动衍射线所改变的晶格常数会在 PDIndexer 关闭时被保存。因此重新启动并不能撤销更改。

- 若要恢复到本次会话中载入该晶体时的晶格常数，请右键单击晶体信息并选择 `还原晶胞常数`。
- 若要将整个晶体列表恢复到刚安装后的状态，请选择 `文件` ▸ `将晶体恢复到初始状态`。

### 晶体列表中出现奇怪的数值或重复项，或缺少压力标准物质（Au、Pt 等）。

`文件` ▸ `将晶体恢复到初始状态` 会恢复包括压力标准物质在内的初始晶体列表。你自己添加的晶体会丢失，如有需要请事先保存。

### 强度比未被计算，所有衍射线的高度都相同。

要计算强度比，晶体需要含有原子位置，并且必须开启 [`计算强度比`](../3-crystal-parameter.md)。入射线设置错误也会导致强度不正确。详情请参见 [故障排除](troubleshooting.md)。

### 如何从 CSManager 或 CIF 文件导入晶体？

- **从 CSManager 导入**：先打开 PDIndexer 的 `晶体参数` 窗口并开启 `选项` ▸ `监视剪贴板`，然后在 CSManager 中选择该晶体。无需先导出 CIF。
- **CIF / AMC 文件** 可以拖放到晶体参数窗口的晶体信息区域。
- 也可以搜索 **内置晶体数据库**（AMCSD）。参见 [晶体参数](../3-crystal-parameter.md)。

无论哪种方式，晶体都会显示在晶体信息区域中。按下 `添加` 即可将其保留在晶体列表中。

### 能否将 X 射线数据与电子（或其他波长）数据叠加在同一横轴上？

可以。PDIndexer 只有一个横轴，所有已载入的谱图都会换算为在 `横轴` 选项卡中选择的入射线种类和波长。例如，电子衍射谱图可以按 Cu Kα 的 2θ 刻度显示。

如果 `横轴` 选项卡中的 `读取谱图后调整横轴` 处于开启状态，轴设置会切换为每次新载入文件的设置。若要固定横轴以便比较，请取消此选项。

## 读取谱图与横轴 {#profiles-and-axis}

### 主窗口的 `横轴` 选项卡与谱图参数窗口中的 `轴设置` 有什么区别？

- **`横轴` 选项卡**（主窗口）只决定 **数据的显示方式**；谱图数据本身不会改变。
- **[`轴设置`](../4-profile-parameter.md#axis-setting)**（谱图参数窗口）会改写 **谱图的测量条件**（入射线种类、波长、出射角等）。如果读取文件时选错了入射线种类或波长，请在此处更正。如果以错误的 **单位** 输入了数值，请重新读取原始文件。

### 能量色散（白色 X 射线）数据（`.npd` / `.nxs`）的横轴不正确，或不显示衍射线。

请在读取文件时显示的对话框中，确认 **能量单位（eV / keV）**、**2θ**，以及（对于 `.nxs`）**通道—能量校准系数** 与测量条件一致。`.npd` 文件使用文件中的能量列，因此也请检查原始文件中的数值和单位。单位错误会使峰位置大幅偏移。

### PDIndexer 能否读取 GSAS `.gsa` 文件（2θ 以厘度为单位）或 q（波数）轴的数据？

可以。

- 对于 `.gsa` 文件（以空格分隔的三列，2θ 以厘度为单位），请在数据转换对话框中选择 2θ 作为横轴，并选择厘度（centi-degree）作为单位。
- 对于 q（波数）轴的数据，请选择 q 作为横轴。也可以在 q 轴上精修晶格常数。

## 峰拟合与晶格常数 {#fitting}

### `搜索范围` 应设为多少？改变它时体积也会变化。

`搜索范围` 是峰中心两侧各自的搜索宽度。请从峰的 **半高全宽（FWHM）的 2～3 倍** 开始，若与相邻峰重叠则将其缩小。范围过宽会把其他峰或背景包含进来，过窄则会截掉峰的尾部；两者都会使拟合位置发生偏移。使用较多的 **高角度峰** 可以提高晶格常数的精度。

### `优化后的晶胞参数` 中显示的数值是否已经应用到晶体上？

没有。`优化后的晶胞参数` 只是 **显示** 由所选反射和拟合条件得到的数值。若要覆盖晶体的晶格常数，请按 `应用到所选晶体`。若要在不改变晶体的情况下使用这些数值，请使用 `复制到剪贴板`。多按几次 `应用到所选晶体` 可能有助于收敛，因为每次都会更新计算出的衍射线位置。

### 选择了相同的反射，但体积的误差突然变大。

峰拟合（对每个峰拟合函数）与晶格常数精修是彼此独立的计算。PDIndexer 只在每个反射的搜索范围内寻找峰，因此如果其他物相的峰或噪声落入该范围，就会有错误的 d 值进入晶格常数的计算。

- 在反射列表中检查每个反射的拟合情况，排除可疑的峰或弱峰。
- 信噪比较差时，先只用强峰进行精修，之后再加入较弱的峰。所需独立反射的数目至少要等于该晶系独立晶格常数的个数（立方晶系为 1，三斜晶系为 6），若要估算误差则需要更多。
- 对于弱峰或重叠严重的谱图，Rietveld 分析等全谱拟合可能更合适。

晶格常数及其误差的计算方法请参见 [算法说明](algorithms.md#lattice-refinement)。

## 连续分析与宏 {#sequential-and-macro}

### 我想自动拟合大量谱图（时间分辨、压力步进等），并求得晶格常数或压力。

请使用 [连续分析](../7-sequential-analysis.md)（从主窗口的工具栏或用 `Ctrl+Shift+S` 打开）。运行前请 **打开峰拟合窗口** 并选择晶体和反射。至少需要四个谱图。结果可以自动保存。

- 一次读取数千个谱图会占用大量内存。请先用约 100 个谱图确定条件，再对全部数据运行。
- 直接从网络文件夹读取会很慢。请在分析前将文件复制到本地磁盘。
- 如果晶格常数在序列中变化很大，峰可能会离开其搜索范围，从而拾取到其他峰。开启 `容差系数` 后，体积与 **运行开始时的体积** 相差超过设定值（%）的点会以 NaN 输出。

### 连续分析能否同时拟合多个物相（例如样品和压力标记物）？

所有已勾选晶体的峰都会被拟合（将峰分离设为 `对所有晶体` 时，不同物相相互重叠的峰会一并分离）。但每次连续分析只记录峰拟合窗口中所选的一种晶体的晶格常数和压力。若要获得其他物相的结果，请选择该晶体后再次运行，或使用在晶体之间切换的 [宏](../8-macro.md)。

### 我对按方位角分割的谱图进行了应力分析，但 `Singh 方程` 选项卡是空的。

只有当 **谱图列表中第一个谱图的名称以 `whole` 结尾** 时，才会进入应力分析模式。对于第二个及以后的谱图，名称中 **最后一个连字符之后** 的文本会被读取为方位角（度）（例如 `sample-30`）。另请确认至少已载入四个谱图，并且峰拟合窗口处于打开状态。在普通运行（非应力模式）中，`Singh 方程` 选项卡保持为空。详情请参见 [连续分析](../7-sequential-analysis.md)。

### 使用逗号作为小数分隔符时，连续分析 CSV 的列发生错位。

连续分析的 CSV 直接沿用屏幕上显示的数字，因此若小数分隔符为逗号（`1,5`），小数部分就无法与列分隔符区分。目前请使用结果选项卡上的 `复制` 将表格以制表符分隔文本的形式复制，再以制表符分隔数据的形式粘贴到电子表格中。谱图本身的 CSV 导出（`文件` ▸ `导出所选谱线`）无论区域设置如何，始终以 `.` 作为小数分隔符。

### 宏用什么语言编写？文件路径应如何书写？

宏使用 **Python（IronPython）** 编写。Windows 路径请用正斜杠书写（`'C:/data/sample.pdi2'`），或写成原始字符串（`r'C:\data\sample.pdi2'`）。可用的函数列在 [宏](../8-macro.md) 的函数参考中。

## 状态方程 {#eos}

### 我输入了温度。结果作为高温下的压力是否有效？

有些状态方程（EOS）在原始论文中没有温度项（等温方程），此时输入的温度不会被使用。对文献中的数值表进行插值的 EOS，**在该数值表的温度和体积范围之外给出的压力并不准确**。请在 [状态方程](../5-equation-of-states.md) 中确认 EOS 的出处和适用范围。

## 其他问题 {#others}

### 报告缺陷时应提供哪些信息？

请在 [GitHub Issues](https://github.com/seto77/PDIndexer/issues) 中附上以下内容进行报告。

- PDIndexer 的版本（`帮助` ▸ `关于 PDIndexer`）和 Windows 的版本
- 能够重现问题的、可以共享的最小文件集（谱图、晶体列表 `.xml`、IPAnalyzer 设置文件等）
- 你执行的操作步骤，以及错误消息或屏幕截图
- 你期望的结果（你认为正确的数值）
