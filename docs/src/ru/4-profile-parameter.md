# Параметры профиля

При нажатии на значок `Параметры профиля (P)` в главном окне открывается это подчинённое окно. Здесь выполняются подробные настройки загруженных профилей и различная числовая обработка.

![Окно параметров профиля целиком](../assets/cap-ru-auto/FormProfileSetting.png)

В левой части окна находится [список профилей](#profile), а правая часть разделена на три вкладки — [Обработка профиля](#profile-processing), [Настройка осей](#axis-setting) и [Операции с профилем](#profile-operator). Каждый шаг обработки можно включать и выключать флажком, и они применяются по порядку сверху вниз.

!!! note
    Настройки, сделанные в этом окне, отражаются на профилях в [главном окне](1-main-window.md) в реальном времени. Единица отображения горизонтальной оси выбирается на вкладке `Горизонтальная ось` главного окна. Настройки на стороне кристалла — такие как подписи индексов дифракционных линий — см. в разделе [Параметры кристалла](3-crystal-parameter.md).

---

## Список профилей {#profile}

Список в левой части окна показывает ту же информацию, что и список профилей в главном окне. Выбор профиля в списке делает его объектом обработки и настроек в правой части окна.

| Элемент | Описание |
| --- | --- |
| `↑` `↓` (кнопки со стрелками вверх/вниз) | Изменяют порядок профилей в списке. |
| `Удалить` | Удаляет выбранный профиль. |
| `Удалить все` | Удаляет все профили. |

В области `Основные сведения` под списком редактируются основные атрибуты выбранного профиля.

| Элемент | Описание |
| --- | --- |
| `Line color` | Нажмите, чтобы изменить цвет отрисовки выбранного профиля. |
| `Line width` | Задаёт толщину линии профиля (`pt`). |
| `Название профиля` | Задаёт имя профиля. |
| `Комментарий` | Поле для произвольного комментария. |

## Обработка профиля {#profile-processing}

На вкладке `Обработка профиля` к выбранному профилю применяется различная числовая обработка. Шаги 1–7 можно включать независимо друг от друга флажком, и включённые шаги применяются по порядку номеров.

### 1. Смещение 2θ {#two-theta-offset}

![Панель смещения 2θ](../assets/cap-ru-auto/FormProfileSetting.tabControl1.tabPage2.flowLayoutPanel1.flowLayoutPanelTwoThetaOffset.png)

`1. 2θ-смещение (для угло-дисперсионной дифрактометрии)` корректирует угол для данных угло-дисперсионной дифрактометрии. Формула коррекции — квадратичная функция от \( \tan\theta \).

$$ \Delta(2\theta) = a_0 + a_1 \tan\theta + a_2 \tan^2\theta $$

Если профиль содержит внутренний стандарт (образец с известными параметрами решётки), нажмите кнопку `Калибровка по внутреннему стандарту` и следуйте появляющимся сообщениям — коэффициенты квадратичной функции будут определены автоматически. В диалоге калибровки наблюдаемые положения пиков сопоставляются с теоретическими положениями пиков эталона, и по ним подбираются коэффициенты.

![Диалог калибровки 2θ](../assets/cap-ru-auto/FormTwoThetaCalibration.png)

Кнопка `Сбросить` сбрасывает установленные коэффициенты смещения.

!!! tip
    В качестве внутренних стандартов обычно используются материалы с точно определёнными параметрами решётки, такие как Si или LaB₆. После калибровки скорректированные значения 2θ используются напрямую во всём дальнейшем анализе.

### 2. Маскирование и интерполяция {#mask}

![Панель маскирования и интерполяции](../assets/cap-ru-auto/FormProfileSetting.tabControl1.tabPage2.flowLayoutPanel1.flowLayoutPanelMaskingMode.png)

`2. Маскирование и интерполяция` маскирует заданный угловой диапазон (или диапазон энергий) и интерполирует профиль, используя интенсивности вне маскированного диапазона.

| Элемент | Описание |
| --- | --- |
| `Задать диапазон маскирования` | Задаёт диапазон горизонтальной оси для маскирования. |
| `Point No.` | Задаёт число конечных точек (с каждой стороны), используемых для интерполяции. |
| `Polynomial order` | Задаёт порядок полинома, используемого для интерполяции. |
| `Сохранить диапазоны маскирования` / `Загрузить диапазоны маскирования` | Сохраняет настроенные диапазоны маскирования в файл или считывает их обратно. |
| `Удалить` / `Удалить все` | Удаляет отдельный диапазон маскирования или все сразу. |

### 3. Сглаживание {#smoothing}

![Панель сглаживания](../assets/cap-ru-auto/FormProfileSetting.tabControl1.tabPage2.flowLayoutPanel1.flowLayoutPanelSmoothing.png)

`3. Сглаживание` применяет сглаживание к выбранному профилю. Алгоритм сглаживания — метод `Savitzky-Golay`.

В этом методе для каждой рассматриваемой позиции \(x\) выполняется аппроксимация методом наименьших квадратов полиномом степени `Order` по данным в пределах \(\pm\) `Point No.` от этой точки, и значение полученной функции \(F(x)\) принимается как новая интенсивность в этой позиции \(x\).

!!! note
    При `Order` \(= 1\) сглаживание Savitzky–Golay эквивалентно простому скользящему среднему. Увеличение `Order` лучше сохраняет форму пиков, а увеличение `Point No.` усиливает сглаживание.

### 4. Полосовой фильтр {#bandpass}

![Панель полосового фильтра](../assets/cap-ru-auto/FormProfileSetting.tabControl1.tabPage2.flowLayoutPanel1.flowLayoutPanelBandPassFilter.png)

`4. Полосовой фильтр` использует преобразование Фурье (FFT), чтобы отсечь составляющие выше или ниже заданных частот.

| Элемент | Описание |
| --- | --- |
| `Срезать высокие частоты выше` | Удаляет составляющие с частотой выше заданного значения (снижает высокочастотный шум). |
| `Срезать низкие частоты ниже` | Удаляет составляющие с частотой ниже заданного значения (устраняет медленно меняющийся фон). |

### 5. Удаление Kα2 {#remove-ka2}

`5. Удалить Kα2 (если Kα1 используется как источник рентгеновского излучения)`: если выбранный профиль был измерен рентгеновским излучением, в котором Kα1 и Kα2 не разделены, и он был загружен с указанием Kα1, включение этого флажка удаляет дифракционную интенсивность, обусловленную Kα2.

!!! warning
    Эта обработка эффективна только в том случае, если в качестве источника рентгеновского излучения выбран Kα1. Проверьте и задайте единицу горизонтальной оси и тип излучения на вкладке [Настройка осей](#axis-setting).

### 6. Фон {#background}

![Панель вычитания фона](../assets/cap-ru-auto/FormProfileSetting.tabControl1.tabPage2.flowLayoutPanel1.flowLayoutPanelBackgroundSubtraction.png)

`6. Фон` вычитает фон из профиля. Есть два метода.

#### B-Spline curve

При нажатии `Автоопределение` фон автоматически вычисляется и вычитается. Параметр `Point No.` задаёт максимальное число опорных точек фона, которые ищутся автоматически.

Опорные точки можно также изменять вручную. Перетаскивайте мышью круглые опорные точки, нарисованные в главном окне, чтобы построить подходящую кривую.

#### Reference

Для выбранного профиля можно указать в качестве фона другой профиль. Флажок `Показать профиль фона` отображает профиль, используемый в качестве фона.

!!! note
    Вычитание фона (шаг 6) исключено из массового применения кнопкой `Применить ко всем профилям (без настройки фона)`, описанной ниже.

### 7. Нормировка интенсивности {#normalize}

![Панель нормировки интенсивности](../assets/cap-ru-auto/FormProfileSetting.tabControl1.tabPage2.flowLayoutPanel1.flowLayoutPanelNormarizeIntensity.png)

`7. Нормировать интенсивность` нормирует профиль так, чтобы `Среднее` или `Максимум` в заданном диапазоне горизонтальной оси стало заданной интенсивностью.

| Элемент | Описание |
| --- | --- |
| `Среднее` / `Максимум` | Выбор, использовать ли в качестве опорного значения среднее или максимум в диапазоне. |
| `in the range` | Задаёт целевой диапазон горизонтальной оси. |
| `to` | Задаёт целевое значение интенсивности после нормировки. |

### Кнопка Apply for all profiles {#apply-all}

Кнопка `Применить ко всем профилям (без настройки фона)` применяет настройки шагов 1–7, **за исключением 6. Фон**, сразу ко всем профилям.

## Настройка осей {#axis-setting}

На вкладке `Настройка оси` заново задаются исходный тип горизонтальной оси, длина волны, угол отбора и время экспозиции выбранного профиля. Единица отображения горизонтальной оси выбирается не здесь, а на вкладке `Горизонтальная ось` главного окна.

| Элемент | Описание |
| --- | --- |
| `Настройка горизонтальной оси` | Задаёт исходный тип горизонтальной оси, длину волны и угол отбора; кнопка `Изменить` записывает их обратно в выбранный профиль. С помощью `Сдвиг` можно также сместить всю горизонтальную ось. |
| `Exposure Time` | Задаёт время экспозиции (`сек.`), используемое в режиме CPS (`(for CPS mode)`). |
| `Настройка вертикальной оси` | Настройки, связанные с вертикальной осью. |

!!! note
    Нажатие `Изменить` записывает исходный тип оси, угол отбора, длину волны и время экспозиции обратно в профиль. В отличие от чисто отображаемого переключения осей в главном окне, это влияет на то, как интерпретируются сами данные. Поскольку длина волны и угол отбора напрямую влияют на расчёт положений дифракционных линий, задавайте правильные значения. Неверно выбранную при импорте единицу ввода здесь исправить нельзя; откройте исходный файл заново.

## Операции с профилем {#profile-operator}

На вкладке `Операции над профилями` выполняется усреднение нескольких профилей и арифметические операции между профилями.

Указав целевые профили для вычисления и нужную операцию, нажмите кнопку `Вычислить` — результат будет добавлен как новый профиль.

| Режим | Описание |
| --- | --- |
| `Усреднение` | Усредняет несколько профилей. |
| `Профиль и значение` | Выполняет операцию между профилем и скалярным значением. |
| `Два профиля` | Выполняет арифметическую операцию (например, сложение) между двумя профилями. |

С помощью `Имя выходного профиля` можно задать имя создаваемого профиля (по умолчанию `Result #01`).

!!! tip
    Это можно использовать, например, для усреднения нескольких измерений с целью улучшения отношения сигнал/шум, либо для взятия разности двух профилей, чтобы выделить изменение между ними.
